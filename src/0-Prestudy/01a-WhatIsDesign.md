# 1. What is the purpose of software design and how is it different from coding?

Coding is the very act of writing code, software desing is the process of architecting the solution.
How to structure and organize the code.

# 2. What is "good" design and "bad" design? How can you tell them apart?

Good desing could be considered code that scales, that is easy to maintain, that is self documenting.
Bad desing would be the opposite.

# 3. If you are beginning a new project, how do you start with the design?

I start from a skeleton, what are the components I need, and start from there. Maybe using a cookiecutter for my project

# 4. What is the hardest part of design. What is most likely to make a design fail?

Having a robust setup that adapts easily to changing requirements.
